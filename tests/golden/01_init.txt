### init discovers sibling git repos and records their default base

$ becket init
[exit 0]
--- stdout ---
▸ Scanning for git repos in <SANDBOX>/platform...
▸ Found repo: admin (base: main)
▸ Found repo: service (base: main)
▸ Created <SANDBOX>/platform/.becket/settings.json

# settings.json
{
  "$schema": "./settings.schema.json",
  "repos": {
    "admin": {
      "path": "./admin",
      "defaultBase": "main"
    },
    "service": {
      "path": "./service",
      "defaultBase": "main"
    }
  },
  "branchPrefix": "feature/"
}
