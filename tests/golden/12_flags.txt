### create --base overrides the base branch the worktree is cut from

$ becket create feat --repos service --base develop
[exit 0]
--- stdout ---
▸ Created workspace: <SANDBOX>/platform/.becket/workspaces/feat
▸ Creating worktree: service → feature/feat (base: develop)
HEAD is now at <SHA> init service

▸ Workspace feat ready at <SANDBOX>/platform/.becket/workspaces/feat
▸ Branch: feature/feat
--- stderr ---
Preparing worktree (new branch 'feature/feat')

# manifest: feat
{
  "$schema": "./workspace.schema.json",
  "id": "feat",
  "created": "<DATE>",
  "description": "",
  "repos": {
    "service": {
      "branch": "feature/feat",
      "base": "develop"
    }
  }
}


### teardown without --delete-branches removes the worktree but keeps the branch

$ becket teardown feat
[exit 0]
--- stdout ---
▸ Removing worktree: service
▸ Removed workspace: feat

# branches: service
develop
feature/feat
main

# workspaces tree

### add with the workspace id detected from the current directory (single-arg form)

$ becket add admin
[exit 0]
--- stdout ---
▸ Creating worktree: admin → feature/multi (base: main)
HEAD is now at <SHA> init admin
▸ Added admin to workspace multi
--- stderr ---

      "branch": "feature/multi",
      "base": "main"

    "admin": {
      "branch": "feature/multi",
      "base": "main"
    }
  }
}
