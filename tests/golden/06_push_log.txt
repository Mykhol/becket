### log shows commits on the feature branch ahead of base

$ becket log ws
[exit 0]
--- stdout ---

service  feature/ws
──────────────────────────────────────────────────
* <SHA> feat: add FEATURE.md


### push the feature branch to origin

$ becket push ws
[exit 0]
--- stdout ---
▸ Pushing service → origin/feature/ws...
branch 'feature/ws' set up to track 'origin/feature/ws'.

▸ Push complete.
--- stderr ---
To <SANDBOX>/origins/service.git
 * [new branch]      feature/ws -> feature/ws

# branches: service
feature/ws
main

### log still works after the branch exists on origin

$ becket log ws
[exit 0]
