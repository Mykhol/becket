### create a workspace scoped to one repo, with a description

$ becket create proj-42 --desc dark mode --repos service
[exit 1]
--- stdout ---
▸ Created workspace: <SANDBOX>/platform/.becket/workspaces/proj-42
▸ Creating worktree: service → feature/proj-42-dark-mode (base: main)
HEAD is now at <SHA> init service
--- stderr ---
Preparing worktree (new branch 'feature/proj-42-dark-mode')
<SANDBOX>/opt/bin/becket: line 419: files[@]: unbound variable

# manifest: proj-42
{
  "$schema": "./workspace.schema.json",
  "id": "proj-42",
  "created": "<DATE>",
  "description": "dark mode",
  "repos": {
    "service": {
      "branch": "feature/proj-42-dark-mode",
      "base": "main"
    }
  }
}


# branches: service
feature/proj-42-dark-mode
main

# worktrees: service
<SANDBOX>/platform/.becket/workspaces/proj-42/service  <SHA> [feature/proj-42-dark-mode]
<SANDBOX>/platform/service                             <SHA> [main]
