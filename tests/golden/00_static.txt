### version

$ becket version
[exit 0]
--- stdout ---
becket v<VERSION>

$ becket --version
[exit 0]
--- stdout ---
becket v<VERSION>

$ becket -v
[exit 0]
--- stdout ---
becket v<VERSION>

### help (explicit, and as the default command)

$ becket help
[exit 0]
--- stdout ---
becket — cross-repo git-worktree workspaces.

Create feature-scoped workspaces of coordinated git worktrees across
multiple repositories, all on a shared feature branch.

Usage:
  becket [flags]
  becket [command]

Platform Commands:
  init        Initialize .becket/ in current directory
  list        List all active workspaces
  stats       Show local command usage statistics
  upgrade     Update config + schemas to latest version

Workspace Commands:
  add         Add a repo to an existing workspace
  adopt       Adopt existing branches into a new workspace
  create      Create workspace + worktrees
  teardown    Remove worktrees + workspace

Develop Commands:
  dev         Start dev environment (docker + tmux)
  setup       Run setup commands for workspace repos
  shell       Print workspace directory path (use with shell-init)
  shell-init  Output shell wrapper for eval (enables 'becket shell' as cd)

Sync & Ship Commands:
  desc        Set workspace description
  log         Show commits across all repos since branching
  pr          Open GitHub PRs for all repos (requires gh)
  push        Push all repo branches to origin
  restack     Rebase a stacked workspace onto its parent's current tips
  status      Show branch status across repos
  sync        Rebase all repos against their base branch

Additional Commands:
  completion  Generate the autocompletion script for the specified shell
  help        Help about any command
  version     Show version

Flags:
  -h, --help      help for becket
  -v, --version   Show version

Use "becket [command] --help" for more information about a command.

### shell-init (shell wrapper + completion bootstrap)

$ becket shell-init
[exit 0]
--- stdout ---
becket() {
  if [[ "$1" == "shell" ]]; then
    local _becket_dir
    _becket_dir="$(command becket shell "${@:2}")" || return $?
    builtin cd "$_becket_dir"
  else
    command becket "$@"
  fi
}
if [[ -n "$ZSH_VERSION" ]]; then
  source <(command becket completion zsh)
elif [[ -n "$BASH_VERSION" ]]; then
  source <(command becket completion bash)
fi
