### set a status note from inside the workspace (id detected from CWD)

$ becket status set blocked on review --by alice
[exit 0]
--- stdout ---
▸ Status set for ws-a: blocked on review

# manifest: ws-a
{
  "$schema": "./workspace.schema.json",
  "id": "ws-a",
  "created": "<DATE>",
  "description": "",
  "repos": {
    "service": {
      "branch": "feature/ws-a",
      "base": "main"
    }
  },
  "status": {
    "text": "blocked on review",
    "updatedAt": "<TS>",
    "updatedBy": "alice"
  }
}


### status (no id) from inside the workspace shows that workspace

$ becket status
[exit 0]
--- stdout ---

Workspace: ws-a
  Status: blocked on review (alice, just now)

  REPO     BRANCH         STATUS     AHEAD/BEHIND   LAST COMMIT
  ───────  ─────────────  ────────   ────────────   ───────────
  service   feature/ws-a   clean      +0 / -0        <RELTIME>


### clear the status note

$ becket status clear
[exit 0]
--- stdout ---
▸ Status cleared for ws-a

# manifest: ws-a
{
  "$schema": "./workspace.schema.json",

  "description": "",
  "repos": {
    "service": {
      "branch": "feature/ws-a",
      "base": "main"
    }
  }
}


### desc with explicit id (run from the platform root)

$ becket desc ws-a first description
[exit 0]
--- stdout ---
▸ Description set for ws-a: first description

{
  "$schema": "./workspace.schema.json",

  "description": "first description",
  "repos": {
    "service": {
      "branch": "feature/ws-a",
      "base": "main"

  }
